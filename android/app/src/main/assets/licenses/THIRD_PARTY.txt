# Bibliotecas de terceros

La aplicación conserva la licencia AGPL-3.0 del proyecto original. El código de terceros mantiene sus autores y licencias originales.

| Biblioteca | Versión | Uso y licencia |
| --- | --- | --- |
| AndroidX / Jetpack Compose | BOM 2025.10.01 | Interfaz Android; Apache-2.0 |
| Kotlin / kotlinx.coroutines | 2.2.21 / 1.10.2 | Lenguaje y concurrencia; Apache-2.0 |
| MuPDF Fitz | 1.28.5 | Maquetación y lectura; AGPL-3.0 |
| JSch, mantenimiento mwiede | 2.28.8 | SFTP/SSH; BSD |
| libarchive Android | 1.1.6 | Contenedores de cómics; wrapper Apache-2.0, libarchive BSD |
| jchmlib | v0.5.4 | Extracción CHM; Apache-2.0 |
| DjVuLibre | 3.5.30.1 | Lectura DjVu; GPL-2.0-or-later |
| libjpeg-turbo | 3.2.1 | Capas JPEG de DjVu; licencias IJG/BSD/zlib según archivo |
| libmobi | 0.12 | MOBI, AZW y KF8; LGPL-3.0-or-later |
| caj2pdf-core | 0.8.1 | Conversión CAJ nativa; MIT |
| jni, Rust | 0.21.1 | Adaptador JNI CAJ; MIT/Apache-2.0 |

Las fuentes C/C++ y Rust usadas para DjVu, MOBI y CAJ están incluidas en `android/app/src/main/`, con sus avisos. Los archivos `cpp/vendor/README.md` y `rust/README.md` registran procedencia, versión y hashes de los paquetes originales. Las dependencias Rust restantes están fijadas con sus checksums en `rust/comics-caj/Cargo.lock`.

El código original web y de escritorio no se empaqueta en el APK nativo.
